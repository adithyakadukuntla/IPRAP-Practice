# Data Lineage - Snowflake Data Engineering

## Data Flow

Participant 1 (Raw Data Generation)
    ↓
Participant 2 (Data Quality & Standardization)
    ↓
data/cleaned/*_clean.csv
    ↓
Participant 3 (Snowflake)
    ├── STAGING Tables (Raw CSV load from Participant 2)
    │   ├── CLIENT_STAGE
    │   ├── PORTFOLIO_STAGE
    │   ├── SECURITY_STAGE
    │   ├── HOLDING_STAGE
    │   └── PERFORMANCE_STAGE
    ↓
    ├── CORE Tables (MERGE from STAGING by business key)
    │   ├── CLIENT
    │   ├── PORTFOLIO
    │   ├── SECURITY
    │   ├── HOLDING
    │   └── PORTFOLIO_PERFORMANCE
    ↓
    └── ANALYTICS Views
        ├── V_PORTFOLIO_SUMMARY
        ├── V_PORTFOLIO_HOLDINGS
        ├── V_PORTFOLIO_ALLOCATION
        ├── V_PORTFOLIO_PERFORMANCE
        ├── V_PORTFOLIO_RISK
        └── V_CLIENT_PORTFOLIO_SUMMARY
    ↓
Participant 4 (APIs)  |  Participant 7 (Power BI)


## STAGING to CORE Mapping

CLIENT_STAGE → CLIENT (MERGE by CLIENT_ID)
PORTFOLIO_STAGE → PORTFOLIO (MERGE by PORTFOLIO_ID)
SECURITY_STAGE → SECURITY (MERGE by SECURITY_ID)
HOLDING_STAGE → HOLDING (MERGE by HOLDING_ID)
PERFORMANCE_STAGE → PORTFOLIO_PERFORMANCE (MERGE by PERFORMANCE_ID)


## CORE to ANALYTICS Mapping

CORE.PORTFOLIO + CORE.HOLDING + CORE.PORTFOLIO_PERFORMANCE → V_PORTFOLIO_SUMMARY
CORE.HOLDING + CORE.PORTFOLIO + CORE.SECURITY → V_PORTFOLIO_HOLDINGS
CORE.HOLDING + CORE.SECURITY → V_PORTFOLIO_ALLOCATION
CORE.PORTFOLIO_PERFORMANCE + CORE.PORTFOLIO → V_PORTFOLIO_PERFORMANCE
ANALYTICS.V_PORTFOLIO_SUMMARY + CORE.HOLDING → V_PORTFOLIO_RISK
CORE.CLIENT + ANALYTICS.V_PORTFOLIO_SUMMARY → V_CLIENT_PORTFOLIO_SUMMARY

## Validation Queries

### 1. Duplicate Check
SELECT PORTFOLIO_ID, COUNT(*) FROM CORE.PORTFOLIO
GROUP BY PORTFOLIO_ID HAVING COUNT(*) > 1;

Result: No duplicates found - PASS

### 2. Orphan Check (Portfolio without Client)
SELECT p.PORTFOLIO_ID FROM CORE.PORTFOLIO p
LEFT JOIN CORE.CLIENT c ON p.CLIENT_ID = c.CLIENT_ID
WHERE c.CLIENT_ID IS NULL;

Result: No orphans found - PASS

### 3. Orphan Check (Holding without Portfolio or Security)
SELECT h.HOLDING_ID FROM CORE.HOLDING h
LEFT JOIN CORE.PORTFOLIO p ON h.PORTFOLIO_ID = p.PORTFOLIO_ID
LEFT JOIN CORE.SECURITY s ON h.SECURITY_ID = s.SECURITY_ID
WHERE p.PORTFOLIO_ID IS NULL OR s.SECURITY_ID IS NULL;

Result: No orphans found - PASS

### 4. Negative Values Check
SELECT PORTFOLIO_ID, INITIAL_VALUE, CURRENT_VALUE
FROM CORE.PORTFOLIO
WHERE INITIAL_VALUE < 0 OR CURRENT_VALUE < 0;

Result: No negative values found - PASS
